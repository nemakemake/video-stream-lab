# Video Stream Lab

Инструмент для глубокого анализа видеопотока с ESP32-S3 + камеры (OV5640):
гистограммы, waveform/vectorscope, 2D FFT спектр, метрики канала (FPS/latency/потери),
плюс живое управление настройками камеры.

## Структура

- `desktop/` — Qt-приложение (приёмник видео, анализаторы, UI).
- `firmware/` — прошивка ESP32-S3 (PlatformIO, framework = espidf).
- `mock/` — Python-скрипт, эмулирующий протокол камеры по TCP. Нужен, чтобы
  разрабатывать и тестировать `desktop/` ещё до того, как готова прошивка/железо.

## Протокол (v1)

Два TCP-канала:

- **Видео** (порт по умолчанию `3333`): сервер (ESP32 или mock) шлёт кадры подряд как
  `[4 байта, big-endian: длина JPEG][JPEG байты]`.
- **Управление** (порт по умолчанию `3334`): текстовые JSON-команды по одной на строку,
  например `{"cmd":"set","param":"exposure","value":300}\n`. Есть также `{"cmd":"get"}` —
  запрос текущих настроек, ответ `{"settings":{...}}` с теми же именами параметров.

## Milestone 1 — видео (готово)

1. Запустить `mock/mock_server.py` — он поднимает видео- и control-порт и шлёт тестовые кадры.
2. Собрать и запустить `desktop/` — окно показывает поток и live FPS.

Клиент не знает, с кем говорит — с ESP32 или с mock: меняется только IP/порт в UI.

## Milestone 2 — управление камерой (готово)

Боковая панель настроек в `desktop/` (`QDockWidget` справа):

- Автоэкспозиция / ручная экспозиция.
- Автоусиление (AGC) / ручной gain.
- Автобаланс белого.
- Качество JPEG.

При подключении control-канала приложение сразу запрашивает `{"cmd":"get"}` и
выставляет элементы UI в реальные значения с устройства — начальные значения
в коде панели после этого не используются, кроме как до первого ответа.

Управление отключается вместе с видео (одно TCP-подключение освобождает слот на ESP32
для другого клиента).

## Прошивка: настройка Wi-Fi

`firmware/src/wifi_credentials.h` не хранится в репозитории (реальный пароль сети).
Перед первой прошивкой:

```bash
cp firmware/src/wifi_credentials.h.example firmware/src/wifi_credentials.h
```

и впишите туда свои `WIFI_SSID`/`WIFI_PASSWORD`.
